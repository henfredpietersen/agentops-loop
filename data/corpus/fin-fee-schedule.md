# Fee Schedule 2025

All fees are in South African Rand and include VAT.

## Programme and admin fees

| Item | Fee | Notes |
|------|-----|-------|
| Higher Certificate | R12 500 | full programme |
| Diploma | R28 000 | full programme |
| Short course | R3 200 | per course |
| Exam re-sit | R850 | per module |
| Late payment fee | R250 | per missed debit order |
| Remark request | R300 | refunded if mark rises 5% or more |
| Course extension | R1 200 | per 3-month extension |

## Fee increases
Fees increase on 1 January each year. Students already enrolled keep their quoted programme fee for the original study period.
