# Technical requirements

| Requirement | Minimum |
|-------------|---------|
| Browser | Chrome or Edge, latest two versions |
| Internet | 5 Mbps for live classes |
| Device | Laptop for exams, phone app for reading |
| Webcam | Required for proctored exams |

Safari is not supported for proctored exams.
